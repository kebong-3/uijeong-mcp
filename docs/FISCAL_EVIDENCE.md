# 예산 근거·직원 확인 링크 개선

사업 조회는 `council_finance_context`에서 지역과 회계연도를 지정한다. 자료 제공 여부를 사업명과 독립적으로 확인하고, 현재일 자료가 없으면 최대 7일 이전까지 찾는다. 실제 제공일 하나를 선택한 뒤 사업명 원문, 띄어쓰기 보정, 등록된 브랜드 후보와 보조어를 순차 검색한다. 사업명만 미발견이라는 이유로 날짜를 과거로 이동하지 않는다. 최대 10회·25초 및 첫 페이지 1,000행 범위를 유지한다. 불완전한 전국 페이지를 완전한 지역 검색이라고 보고하지 않는다.

예산 단계는 current(예산현액), original(의결 본예산), supplementary(의결 추경), draft(예산안), settlement(확정 결산)으로 표시한다. 이 API에서 확인한 것은 현재액·지출액이므로 다른 단계 요청은 PARTIAL과 미확인 상태를 함께 반환한다. 원·천원·백만원을 명세 확인 없이 변환하지 않는다. cpl_amt는 의미가 검증될 때까지 원시 필드로 보존하고, 본예산 또는 확정 편성액의 별칭을 붙이지 않는다. 예산안 심사 회의록에 나온 금액을 최종 의결액이라고 소개하지 않는다.

원문 링크를 이미 확보한 회의록·법규는 그 주소를 사용한다. 원문이 없으면 공식 데이터셋·자료 설명·공식 검색 링크를 제공하고 개별 원문 미확인이라고 표시한다. 링크에 API 키를 넣지 않는다. 링크의 원문/데이터셋/목록/검색 구분과 본문 조회 상태를 보존한다. 자료별 source_links.markdown을 답변의 핵심 사실·수치·조문에 붙이도록 서버 지침을 제공한다. 표시 문구 자체는 호스트 AI가 작성한다.

서구의회 홈페이지 직접 검색을 다시 활성화하지 않고, 기존 서버 주소·40개 도구·인증 없음·API 키 설정·유료 인스턴스를 유지한다.
