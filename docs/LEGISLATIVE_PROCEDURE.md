# 조례·시행규칙 행정절차 점검

2026년 9월 30일 보도된 '조례 심의 전 관련 시행규칙 공포' 사례를 오류 시나리오로 삼았다. 기사 입력은 실제 공보·의결문 조회와 구분하며, 해당 사건의 위법·무효를 자동 확정하지 않는다. 기존 40개 도구와 연결 주소를 유지하고 `ordinance_guide`와 `ordinance_review_project`를 확장했다. 외부 유료 AI 호출은 없다.

## 직원 질문 예시

> 우리 구 조례 개정안은 의회에 제출한 상태인데 관련 시행규칙을 먼저 공포해도 되는지 검토해줘. 근거 조문, 본회의 의결·공포·시행일과 규칙 시행일을 대조하고, 보류할 사항과 담당부서별 확인 증빙, 공식 링크를 알려줘.

AI는 질문에 나온 지역·근거 유형·날짜를 `ordinance_guide`에 전달한다. 미지정 지역·날짜를 만들어 넣지 않는다. 일반 절차는 인자 없이 확인할 수 있다. 원문 ID를 선택한 뒤 `ordinance_get_document`로 본문·부칙·별표를 필요한 구간까지 조회한다. `ordinance_review_project`에서도 같은 procedure를 전달하면 실제 수집한 근거 문서를 대조하고 최종 품질 점검에 보류 사유를 반영한다.

## 입력 예시: 실제 기사 사실 인증이 아닌 재현 시나리오

```json
{
  "as_of": "2026-10-01",
  "procedure": {
    "jurisdiction": "광주 북구",
    "instrument": "rule",
    "action": "promulgate",
    "basis_kind": "ordinance_amendment",
    "basis_title": "가상 지원 조례",
    "basis_article": "제2조",
    "ordinance_stage": "submitted",
    "dates": {
      "ordinance_submission": "2026-09-04",
      "rule_promulgation": "2026-09-15"
    },
    "final_text_matches": "unknown",
    "steps": {"law_review": "pending"}
  }
}
```

결과는 `HOLD_RECOMMENDED`: 본회의 의결 미확인, 조례 공포·근거 시행일 누락, 최종문 대조 미완료, 법무 검토 미완료. `publication_ready`·`implementation_ready`·`legal_approval`은 항상 false이다. 경고가 없더라도 `EVIDENCE_REVIEW_REQUIRED`이며 자동 승인으로 바뀌지 않는다.

## 점검 범위

|점검|처리|
|---|---|
|개정 조례 의존 규칙|의결·공포·근거 시행일과 규칙 날짜 대조|
|현행 조례·법률 근거 규칙|의회 의결을 일률 요구하지 않고 현행 근거·시점·권한 확인|
|본회의 의결·공포 예정일|미래 날짜를 완료 사실로 취급하지 않음|
|상임위 통과·결재 완료|본회의 의결·공포 증거로 대체 불가|
|초안·협의·예고 준비 병행|준비 작업과 발령·실제 적용 구분|
|조례 공포 후 시행 전 규칙 공포|일률 차단하지 않고 실제 시행일·부칙·법무 확인 요구|
|의회 수정의결·부결·철회·재의|최종문·규칙안 조문·별표·금액·서식 재대조|
|입법예고 단축·면제|예외 사유는 경고 해제 입력이 아님. 적용 법규·사유·기간 계산 확인|
|법무·심의·사전보고 등|pending이면 적용되는 선행절차 완료 전 보류 검토. 비대상 판단도 증빙 요구|
|이미 공포·적용한 사고|법무 보고·적용 내역 보존·추가 적용 보류 및 정비 방안 검토. 자동 무효·소급치유·환급 단정 금지|

`basis_document_id`는 검토 중 실제 수집한 공식 원문과 대조한다. 사용자 제공 문서·공식 URL 입력으로 공식성을 승격하지 않는다. 조회한 원문의 전체 시행일과 입력 조항 시행일이 다르면 부칙·조문별 시행일 확인 대상으로 표시한다. 조문의 존재 확인은 위임 의미·적법성의 확정이 아니다.

## 한계와 공식 확인

진행단계·의안번호·공보·협의 증빙을 자동으로 실시간 전수 수집하는 기능은 아니다. 현재 연결된 법령 API의 공식 본문과 사용자가 제시한 진행정보를 구분하여 점검한다. 자료가 부족하면 담당자가 의결문·공보·협의 문서를 확인해야 한다. 해당 지방자치단체의 제출주체별 법제사무 절차·개별법·예외가 우선하며 법정 기한을 자동 산정하지 않는다.

- [지방자치법](https://www.law.go.kr/lsInfoP.do?lsId=001656): 제28조 조례, 제29조 규칙, 제32조 의결·공포·시행 등. 현행 버전·부칙 확인.
- [지방자치법 시행령](https://www.law.go.kr/법령/지방자치법시행령): 심의·공포·보고 경로와 적용 예외 확인.
- [행정절차법](https://www.law.go.kr/법령/행정절차법): 입법예고·기간·예외 확인.
- [법제처 2022 자치법규 입안 길라잡이](https://www.moleg.go.kr/board.es?act=view&bid=0007&list_no=138536&mid=a10404000000): 일반 입안 참고. 현행법을 다시 대조.

링크 제공은 이번 호출에서 해당 본문을 읽었다는 증거가 아니다. 실제 조회한 원문의 증빙 링크와 일반 안내 참고 링크를 구분한다.
