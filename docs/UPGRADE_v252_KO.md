# 2.5.2-public.2 — 원문 링크와 동시 조회 개선

2026-09-22 오잇길 조회에서 재현된 문제를 수정했습니다.

- 공개 회의록의 `key`를 비밀 API 키와 구분합니다. 실제 환경변수 비밀값과 CLIK API 인증키는 계속 가립니다.
- `source_link.markdown` 및 발언의 `citation.citation_markdown`에 클릭 가능한 날짜·회의명 링크를 제공합니다.
- 서구의회 첨부 주소가 있으면 공식 HTML 본문을 확인합니다. 주소가 없으면 공식 날짜순 목록에서 회의를 찾고, 긴 발언 두 개 이상을 대조한 후 연결합니다. 확인되지 않은 링크는 만들지 않습니다.
- 링크 확인은 요청당 최대 25초로 제한합니다. 링크 확인 실패·시간 초과 시 이미 확보한 본문은 유지하고 링크의 미확인 사유를 반환합니다.
- 동시 실행은 3건으로 유지합니다. 추가 요청은 최대 12건, 20초간 대기합니다. 지속적인 과부하는 여전히 503으로 안내됩니다.
- `위원장직무대리`, `의장직무대리`, `임시위원장` 등 발언을 이전 발언자의 내용과 분리합니다. 파서 버전이 2.1로 변경되어 발언번호와 본문 해시는 달라질 수 있습니다.
- 홈페이지 원문의 회기·차수·회의명 필드가 표준 메타데이터에 반영됩니다.
- 배포 후 실조회에서 발견한 목록 페이지 변수 오류(`pageIndex` → `pageNum`)를 수정했습니다. 첫 페이지의 실제 이동 링크를 읽어 오래된 환경설정도 보정하고, 첫 페이지가 반복되면 미조회 구간을 검색 완료로 처리하지 않습니다.
- 목록·본문·robots 확인의 중복 동시 요청을 합치고, 날짜 탐색의 불필요한 인접 페이지 조회를 줄였습니다. 감사 회의명은 공식 HTML 제목에서도 읽습니다.

## 유지한 설정

공개·인증 없음 방식, 공개 도구 10종, 검색 건수 기본값 및 상한을 유지합니다. `max_docs`와 상세 5건의 의미는 이번 변경에서 바꾸지 않았습니다.

## 근거 표시 지침

사용자에게는 `[2025.12.02. 사회도시위원회 회의록 원문](공식 URL)`처럼 표시합니다. `CLIK...` 문서번호와 파싱 발언번호는 내부 추적용 보조 근거이며 링크를 대신하지 않습니다.

`FETCHED_MATCHED`는 공식 HTML의 본문을 대조한 링크입니다. `PROVIDED_NOT_FETCHED`는 출처가 제공한 주소만 확보한 상태입니다. 링크를 찾지 못했을 때는 해당 사실을 알립니다. API 호출 주소, 임의로 만든 발언 앵커, 추측한 공식 문서번호를 원문 링크로 사용하지 않습니다.

## 검증과 범위

- 기존 및 회귀 테스트 489건 통과.
- 회귀 항목: 공식 key 보존, API 키·토큰 차단, 위장 도메인 차단, 주소 없는 회의의 링크 복구, 다른 본문 오연결 차단, 링크 시간 초과 시 근거 유지, 직무대리 발언 분리, 동시 5건 대기 처리, 대기 취소·초과 후 슬롯 회수.
- 공개 SDK 자체검사와 배포 후 실제 오잇길 조회 결과는 작업 보고에서 별도로 확인합니다.
- 서구의회 목록에 게시되지 않은 회의록이나 외부 사이트 장애까지 해결하는 변경은 아닙니다. 다른 의회에 대한 자동 주소 복구 어댑터는 이번에 추가하지 않았습니다.
