# GOV:IMPACT — 법령·제도 변경 행정영향 레이더

법령이 바뀌었을 때 우리 지자체의 조례·규칙 등에서 확인할 대상을 먼저 찾아주는 **비생성형 AI/규칙 기반 행정지원 MVP**입니다.

## 핵심 원리

1. 법제처 `lsHstInf`에서 특정 일자의 법령 변경이력을 조회합니다.
2. `lsJoHstInf`에서 조문 단위 변경이력을 함께 조회합니다.
3. `lnkOrg`의 **법령↔자치법규 공식 연계정보**에서 광주광역시 서구(`3600000`)의 연계 관계를 가져옵니다.
4. 공식 연계가 없을 때는 자치법규 본문(`ordin`, search=2)에서 해당 법령명을 보조 검색합니다.
5. 결과는 “개정 필요”가 아닌 **“검토 필요 후보”**로만 표시합니다.

## API 비용

- OpenAI / Claude API: 사용하지 않음
- 법제처 국가법령정보 공동활용 OPEN API: 별도 인증값 필요

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 업로드
2. Vercel에서 저장소 Import
3. Project Settings → Environment Variables
4. `LAW_OC` = 법제처 OPEN API 인증값 등록
5. 재배포

기본 기관코드:
- 광주광역시: `6290000`
- 광주광역시 서구: `3600000`

다른 지자체는 `AGENCY_CODE`, `PARENT_AGENCY_CODE`만 변경하면 됩니다.

## 안전 설계

- AI가 법률해석이나 개정 필요 여부를 확정하지 않습니다.
- 공식 연계정보 일치와 법령명 본문 검색을 분리 표기합니다.
- 결과는 담당자의 원문 대조를 위한 사전 검토 목록입니다.
- 향후 내부 지침/서식/홈페이지 영향까지 확장할 때도 “후보 탐지 → 사람 검토” 원칙을 유지합니다.
