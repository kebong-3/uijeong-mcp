# ChatGPT Sites 구축 지시문

@Sites

"지방의회·예산·조례"라는 공개 웹사이트를 만들어 주세요. 이 사이트는 지방공무원과 시민이 지방의회 회의록, 지방예산, 조례·시행규칙의 공식 근거를 확인하는 서비스의 제품 사이트이자 ChatGPT 플러그인 호스트입니다.

## 목표
1. 사이트에 MCP 서버를 추가하고 게시할 때 연결된 ChatGPT 플러그인이 생성되도록 구성합니다.
2. 기존 운영 MCP `https://uijeong-mcp.onrender.com/mcp`는 안정판이므로 삭제·변경하지 말고 fallback/기준 서버로 유지합니다.
3. Sites 런타임에서 현재 Python 의존성, 외부 공식 API 호출, 비밀키, SQLite 상태가 안정적으로 동작하는지 먼저 검증합니다.
4. 호환성 확인 전에는 40개 도구를 전부 재작성하지 말고 핵심 읽기 전용 흐름부터 연결·시험합니다.
5. 비밀키는 코드/화면/로그/도구 결과에 넣지 말고 Site owner-only secrets를 사용합니다.

## 데이터 원칙
- 공식 공개자료만 사용합니다.
- CLIK, 지방재정 관련 공식 API, 국가법령정보 공동활용 API 등 현재 서버의 공식 출처를 우선합니다.
- 검색 0건·API 실패·미확인을 근거 없음/0원/미제정으로 단정하지 않습니다.
- 의원 개인 평가·성향·순위를 만들지 않습니다.
- 다른 지자체 조례는 비교자료로만 사용합니다.
- 적법성 승인·의결·공포·전자결재를 대신하지 않습니다.
- 개인정보·비공개 내부자료를 입력받지 않는 공개형 서비스로 설계합니다.

## 화면
메인에 지방의회 / 지방예산 / 조례·입법 세 업무 카드를 배치하고, 상단에 “공식 근거를 먼저 찾고, 확인 수준을 함께 알려드립니다.”를 표시합니다.

페이지:
- `/guide` 사용법과 예시 질문
- `/sources` 공식 출처와 확인 수준
- `/support` 문의·오류 신고
- `/privacy` 개인정보처리방침
- `/terms` 이용약관

## MCP/플러그인
먼저 기존 MCP를 Site에 연결해 도구 목록과 실제 호출을 확인합니다. 다음 핵심 목표를 테스트합니다.
- 특정 사업의 의회 발언 근거 찾기
- 회의록 원문·문맥 읽기
- 예산 공개자료 조회·산출 검산
- 현행 조례 원문·시행일 확인
- 신규사업 조례 근거 검토
- 의회+예산+조례 복합 검토

출력은 확인 범위 → 확인된 사실 → 업무상 해석 → 미확인 사항 → 다음 조치 → 공식 출처 순서를 기본으로 합니다.

## 이전 단계
1단계 기존 Render MCP 연결 + Site UI + 플러그인 생성
2단계 Sites의 secrets/외부 API/캐시 호환성 시험
3단계 읽기 전용 도구부터 Site-hosted MCP로 이전
4단계 Render는 최소 한 릴리스 주기 fallback 유지
5단계 테스트 통과 후 공개 Plugin Directory 제출 준비

완료 후 실제 생성된 MCP 도구 목록, Site URL, 플러그인 연결 상태, Render에 남은 기능을 표로 보여 주세요.
